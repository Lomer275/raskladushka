# Раскладушка — как устроена программа

Описание для тех, кто читает или правит код. Что программа умеет и как ею пользоваться — в [README.md](../README.md).

## Цель

Программа для Windows 10 и 11 x64 с тремя функциями:

1. автосмена раскладки при наборе;
2. исправление раскладки по клавише;
3. голосовой ввод на Whisper, полностью на компьютере пользователя.

Главное требование — программа не должна заметно расходовать ресурсы. В простое: память до 80 МБ, процессор около нуля, видеопамять 0.

## Чего нет

- обработки текста нейросетью;
- языков, кроме русского и английского (США); интерфейса не на русском;
- истории диктовок;
- окна настроек — настройки лежат в текстовом файле;
- работы в окнах, запущенных от имени администратора;
- автосмены посреди слова — решение принимается в конце слова;
- автоматической установки обновлений;
- установки для всех пользователей компьютера.

## Поведение

### Общее

- Значок в трее, автозапуск с Windows, один экземпляр программы (`Local\Raskladushka`).
- Меню значка: «Пауза», «Автосмена раскладки», «Голосовой ввод: скачать…» (или «Голосовой ввод…», когда голос стоит), «Записывать исправленные слова», «Открыть настройки», «Открыть журнал», «Самопроверка», «Автозапуск», «Сообщать об обновлениях», «Проверить обновления», «О программе», «Выход».
- В полноэкранных приложениях, в приложениях из списка исключений и в полях пароля программа ничего не делает: ни автосмены, ни горячих клавиш, ни диктовки.
- При первом запуске — подсказка у значка о клавишах. Если в Windows нет русской или английской раскладки, подсказка говорит об этом: без обеих автосмена не работает. Если запущены Punto Switcher или KeyRay, программа предупреждает, что две программы смены раскладки мешают друг другу.
- Подсказки — всплывающие уведомления у значка, а не окна: окно при запуске с Windows никто не ждёт.

### Голосовой ввод

- Удержание правого Ctrl — запись. Отпускание — распознавание и вставка текста в место курсора.
- Если при удержанной клавише нажата любая другая, это обычное сочетание клавиш: запись отменяется, звук отбрасывается.
- Событие самой клавиши не подавляется: остальные программы видят правый Ctrl как обычно.
- Пока идёт запись, загрузка модели или распознавание, внизу экрана виден индикатор: «Запись», «Загружаю модель…», «Распознаю…».
- Запись короче 0,4 с и запись без звука в Whisper не отправляются.
- Предел одной записи — 120 с, после него запись останавливается и распознаётся.
- После вставленного текста добавляется один пробел.
- Если голос ещё не скачан, нажатие клавиши показывает подсказку «Голосовой ввод ещё не скачан. Нажмите, чтобы скачать».

### Исправление по клавише

- Касание Alt (нажать и отпустить без других клавиш) — последнее набранное слово переводится в другую раскладку, раскладка переключается.
- Касание Alt сразу после автоматической замены — замена отменяется, исходное слово записывается в список исключений.
- Касание Alt после выделения текста, когда набранного слова нет, — выделенный текст переводится в другую раскладку.
- Shift+Pause — перевод выделенного текста.

Касание — это нажатие и отпускание одной клавиши Alt: без Shift, Ctrl и Win, без второй клавиши Alt, без автоповтора и без других нажатий между ними. Щелчок мыши, колесо и боковые кнопки мыши при зажатом Alt, смена окна касание отменяют. Отпускание уже нажатой буквы — нет: при быстром наборе Alt нажимают раньше, чем отпущена последняя буква.

Известные ограничения касания. Если диктовка назначена на `RAlt`, короткое нажатие правого Alt исправит слово. Если одна клавиша Alt удерживается, а вторую коротко нажали, это тоже сочтётся касанием. Случайное касание сразу после автозамены запишет слово в исключения; список лежит в `exceptions.txt` и правится руками.

Нажатие Alt программа не перехватывает, поэтому сочетания с Alt работают как обычно. Перехватывается только отпускание — и только когда есть что исправлять: вместо него программа посылает нажатие клавиши без назначения (код `0xE8`) и своё отпускание Alt. Без этого Windows открыла бы меню окна, а удаление слова ушло бы в программу с зажатым Alt. Когда исправлять нечего, отпускание проходит как есть.

Клавиша исправления задаётся настройкой `layout.fixHotkey`. Кроме касания Alt, это может быть отдельная клавиша: `Pause`, `ScrollLock`, `F13`–`F24`. Тогда выделенный текст переводит Shift + эта клавиша. Касание Alt выбрано по умолчанию, потому что на многих клавиатурах, особенно ноутбучных, нет ни Pause, ни ScrollLock, ни F13–F24. Shift+Alt для перевода выделения не годится — это системная смена языка.

### Перевод выделения

Выделение касанием Alt переводится, только если программа видела, как его сделали: протяжка мышью, двойной или тройной щелчок, щелчок с Shift, Shift с клавишами перемещения (стрелки, Home, End, PgUp, PgDn, в том числе с Ctrl), Ctrl+A. Любая другая клавиша, кроме модификаторов и копирования (Ctrl+C, Ctrl+Insert), и простой щелчок признак снимают.

Причина: перевод выделения начинается с копирования, а копирование без выделения в VS Code берёт всю строку, в Excel — ячейку, в терминале Ctrl+C прерывает процесс. Одиночный Alt там, где выделения не было, должен открывать меню и подсказки ленты, как обычно. Выделение, сделанное иначе (поиск, Ctrl+L в браузере, F2 в Проводнике), программа не замечает — тогда Alt ведёт себя как обычно.

Копирование идёт сочетанием Ctrl+Insert, а не Ctrl+C: в терминале оно ничего не прерывает. Если ничего не скопировалось, текст не меняется, а меню окна не открывается — Alt уже поглощён.

После Ctrl+Insert программа ждёт, пока буфер обмена перестанет меняться:
- первую копию — до 1 с;
- затем тишину не меньше 0,2 с, а если первая копия шла дольше, то не меньше её времени;
- всего не дольше 2 с после первой копии. Если буфер всё ещё меняется, в него пишет кто-то ещё, и перевод не вставляется.

Причина: в веб-панелях VS Code (например, в чатах расширений) Ctrl+Insert может копировать дважды — сначала сама панель, потом VS Code по пересланному нажатию, — и вторая копия затёрла бы перевод. Обычные программы копируют один раз, и в них перевод появляется примерно на 0,2 с позже, чем мог бы.

Перевод вставляется через Ctrl+V. Прежнее содержимое буфера возвращается не раньше чем через 0,5 с после вставки, а если копирование шло долго — через его утроенное время, но не позже 2 с. Причина та же: веб-панели VS Code читают буфер при вставке не сразу, а после круга «панель → VS Code → панель», и при возврате через 150 мс вставлялся исходный текст.

### Автосмена раскладки

- В конце слова программа читает набранные клавиши в обеих раскладках. Если в текущей раскладке получилась бессмыслица, а в другой — нормальное слово, слово заменяется и раскладка переключается.
- Не трогаются: слова короче трёх букв, слова из списка исключений, слова, набранные перед Enter и Tab (заменять поздно).

## Как определяется «не та» раскладка

1. Буфер хранит клавиши, а не символы. Причина: русские «х, ъ, ж, э, б, ю, ё» стоят на клавишах английских знаков препинания, поэтому «люблю» в английской раскладке выглядит как `k.,k.` и по символам на слова не делится.
2. Слово — цепочка клавиш, каждая из которых даёт букву хотя бы в одной из двух раскладок. Слово кончается клавишей, которая не даёт букву ни в одной раскладке: пробел, цифра, клавиша «/» и подобные.
3. В конце слова строятся два прочтения: в текущей раскладке и в другой. С краёв каждого прочтения срезаются знаки препинания этой раскладки.
4. Замены нет, если: в другом прочтении меньше трёх букв; текущее прочтение есть в списке исключений; текущее прочтение — английское слово с апострофом (`don't`, `it's`).
5. Другое прочтение есть в словаре своего языка. Замена — если текущего прочтения в словаре нет либо другое слово встречается в своём языке хотя бы в 100 раз чаще текущего. Знаки препинания по краям текущего прочтения снижают его вес: точка или запятая в конце — в 5 раз, любой другой знак — в 100 раз. Причина: в словарях частых слов есть редкие и мусорные записи (`tot`, `nen`, `tp`), которые совпадают по клавишам с очень частыми русскими словами «еще», «тут», «без».
6. Другого прочтения в словаре нет. Текущее есть в словаре — замены нет. Иначе сравниваются оценки по трёхбуквенным сочетаниям: замена — только когда текущее прочтение неправдоподобно, а другое правдоподобно с запасом.
7. При замене заново набирается и завершающая клавиша слова, тоже в другой раскладке: Shift+«/» в английской раскладке даёт «?», а в русской — запятую.

Буфер сбрасывается без проверки при: щелчке мыши, стрелках и клавишах перемещения, сочетаниях с Ctrl, Alt, Win, клавишах Esc, Enter, Tab, смене активного окна или поля. Backspace убирает из буфера последнюю клавишу.

**Данные.** Словари частых слов на 50 тысяч слов для каждого языка вложены в программу. Таблицы трёхбуквенных сочетаний строятся из них при запуске, около 0,35 с на оба языка. Источник списков — `hermitdave/FrequencyWords` (корпус OpenSubtitles 2018), лицензия данных CC BY-SA 4.0; подробности в [data/src/NOTICE.md](../data/src/NOTICE.md).

**Мера качества** — тест в ядре, отчёт пишется в `artifacts/quality.md`:

| Что меряется | Цель |
|---|---|
| M1 — частые русские слова, набранные в английской раскладке: доля пойманных слов | не меньше 97 % |
| M1-вес — то же, но с учётом частоты слов: доля пойманного русского текста | не меньше 99 % |
| M2 — частые английские слова, набранные в русской раскладке: доля пойманных слов | не меньше 97 % |
| M2-вес — то же с учётом частоты: доля пойманного английского текста | не меньше 98,5 % |
| M3 — редкие слова вне словаря, набранные правильно: доля испорченных | не больше 1 % |
| M4 — технические слова (`nginx`, `kubectl`, `ssh`), набранные правильно: доля испорченных | не больше 1 % |
| M5 — словарные слова, набранные правильно, в том числе с точкой или запятой в конце: доля испорченного текста с учётом частоты | не больше 0,01 % |

Меры с учётом частоты (M1-вес, M2-вес, M5) нужны, потому что доля слов не показывает, что промахи приходятся на самые частые слова.

**Известное ограничение.** Пары, где оба слова частые и набираются одними клавишами, остаются как набраны: «руку» и `here`, «рук» и `her`. Слово «ещё» с буквой «ё» в английской раскладке выглядит как `to` со знаком и тоже не заменяется; «еще» через «е» заменяется. Такие случаи исправляются касанием Alt.

## Устройство

Три части с чёткими границами.

| `Typing/WordBuffer` | Копит клавиши текущего слова; знает, когда слово кончилось и когда буфер надо сбросить | `KeyMap` |

| `Typing/TypingController` | Для каждой клавиши решает: копить, заменить слово, отменить замену, сбросить буфер | `WordBuffer`, `LayoutDetector`, абстракции «вывод клавиш» и «раскладка» |

Ядро целиком покрывается тестами и собирается и тестируется под Linux.

### Оболочка — `Raskladushka.App` (.NET 8 для Windows, WinForms, x64)

Тонкий слой, в котором нет решений — только связь ядра с Windows:

- **Перехват клавиш** — низкоуровневый перехватчик клавиатуры и мыши на отдельном потоке. В обработчике только быстрые операции в памяти: буфер слова, поиск по словарю, отправка замены. Диск, сеть, буфер обмена, запись звука и запуск процессов уходят на рабочие потоки. Причина: Windows молча снимает перехватчик, который отвечает медленно. Сторож переустанавливает перехват, если Windows его сняла.
- **Решение о замене принимается прямо в обработчике**, а завершающая клавиша слова при замене поглощается и набирается заново вместе со словом. Причина: иначе клавиши, нажатые сразу после слова, вклиниваются в замену и портят текст.
- **Замена слова** — один вызов `SendInput`: стирание и повторный набор слова символами Юникода. Один вызов нужен, чтобы настоящие нажатия пользователя не вклинились в середину замены. Собственные события помечаются и перехватчиком игнорируются.
- **Раскладка** — чтение раскладки активного окна и запрос на её смену.
- **Выделенный текст** — копирование, перевод, вставка, восстановление буфера обмена.
- **Запись звука** — микрофон по умолчанию или заданный в настройках, 16 кГц моно, в память. Библиотека NAudio.
- **Whisper** — запуск и остановка процесса, запросы к нему.
- **Вставка надиктованного** — через буфер обмена с восстановлением прежнего содержимого.
- **Пароли** — признак поля пароля определяется при смене фокуса: стиль поля для обычных окон и свойство доступности для браузеров.
- **Полный экран** — запрос состояния у Windows плюс список исключений по имени процесса.
- **Значок, меню, индикатор, окно голоса, «О программе», автозапуск, журнал, проверка обновлений.**

### Whisper — отдельный процесс

- `whisper-server.exe` из сборки whisper.cpp. Слушает только `127.0.0.1`, порт выбирается свободный при каждом запуске.
- Запускается с рабочей папкой голоса и коротким именем модели, без полного пути: так русские буквы в пути к папке пользователя не мешают whisper.cpp открыть модель.
- **Запуск — при нажатии клавиши диктовки**, а не при отпускании: модель грузится, пока пользователь говорит. Готовности ждём до 90 с.
- **Остановка — через `dictation.idleUnloadMinutes` минут без диктовок** (по умолчанию 5). Процесс завершается, видеопамять и оперативная память освобождаются полностью.
- Процесс привязан к программе объектом задания Windows: если программа упадёт, Windows завершит и его.
- **Если сервер под видеокарту не поднялся или вернул ошибку** — один перезапуск на сборке для процессора и уведомление у значка. Если модели для процессора нет, на процессоре запускается основная модель, и уведомление предлагает скачать модель для процессора. Режим процессора действует, пока Whisper не погашен по простою; следующий запуск снова пробует видеокарту. Причина: перезапускать сервер ради каждой диктовки — это заново грузить модель.
- На процессоре число потоков — половина логических процессоров, но не меньше 4 и не больше 8 (`whisper.cpuThreads` задаёт его явно). С четырьмя потоками, как у сервера по умолчанию, распознавание почти в полтора раза медленнее. С видеокартой число потоков не задаётся.

## Диктовка: путь от клавиши до текста

1. Клавиша диктовки нажата → начинается запись; если Whisper не запущен, он запускается.
2. Клавиша отпущена → запись останавливается. Короткая или беззвучная запись отбрасывается.
3. Программа ждёт готовности Whisper до 90 с и отправляет запись.
4. Параметры запроса: язык из настроек, температура 0, строка терминов из настроек.
5. Ответ чистится: сегменты склеиваются через пробел; если сегмент кончается буквой или цифрой, а следующий начинается с заглавной, между ними ставится точка; ответ, целиком совпавший с известной выдуманной фразой («Продолжение следует…», «Субтитры сделал DimaTorzok» и подобные), отбрасывается.
6. Текст кладётся в буфер обмена, посылается Ctrl+V, через 0,5 с прежнее содержимое буфера возвращается.
7. Запускается отсчёт до остановки Whisper.

## Скачивание голоса

Голос в установщик не входит и скачивается, только когда человек сам попросит: пунктом меню или по подсказке после нажатия клавиши диктовки.

Что качать, описывает `src/Raskladushka.Core/Voice/voice-catalog.json`: адрес, имя файла, размер и SHA-256 каждого файла и состав вариантов.

| Вариант | Что качается | Скачать | На диске |
|---|---|---|---|
| Для видеокарты NVIDIA | сборка whisper.cpp под CUDA 12.4, сборка для процессора как запасная, модель `large-v3-turbo` в сжатом виде (`q5_0`) | около 1,3 ГБ | около 1,8 ГБ |
| Для процессора | сборка whisper.cpp для процессора и модель `small` | около 0,5 ГБ | около 0,5 ГБ |

Вариант для видеокарты предлагается, если в списке видеоадаптеров Windows есть NVIDIA и в системе есть `nvcuda.dll`. Выбрать вариант для процессора можно всегда.

Почему `small` для процессора: на 4 потоках фраза в 5 с распознаётся ею за 5,0–5,7 с, на 8 потоках — за 3,1–3,9 с, а `large-v3-turbo` на 4 потоках — за 34–36 с (сборка той же версии под Linux, виртуальный Xeon Skylake, модель загружена заранее). Поэтому у варианта для видеокарты запасная сборка для процессора идёт без своей модели: если видеокарта отказала, программа предлагает докачать `small`.

Порядок установки:
- перед скачиванием проверяется место на диске с учётом архивов, распакованных файлов и модели;
- прерванное скачивание продолжается с места обрыва;
- файл с неверной суммой отвергается: программа его не распаковывает и не запускает;
- из архива сборки распаковываются только `whisper-server.exe` и библиотеки `.dll`, вложенные папки архива уплощаются; архив после распаковки удаляется;
- сборки лежат в `whisper\cuda\` и `whisper\cpu\`, модели — в самой папке `whisper\`;
- рядом с каждой сборкой кладётся копия библиотек Visual C++ из установщика (`msvcp140.dll`, `vcruntime140.dll`, `vcruntime140_1.dll`, `vcomp140.dll`). Сборкам whisper.cpp они нужны, на чистой Windows их нет, а ставить их системно нужны права администратора. Windows сначала ищет библиотеки рядом с запускаемым файлом, поэтому старая системная копия не мешает. Самой программе Visual C++ не нужен;
- в папке сборки лежит метка `.package` с суммой архива. Сборка считается установленной, если есть `whisper-server.exe` и метка совпадает с суммой из каталога; тогда повторная установка её пропускает;
- после установки программа прогоняет через голос тестовую запись `selftest.wav`. Если сборка под видеокарту не запустилась или не распознала запись, окно предлагает вариант для процессора;
- если адреса недоступны, окно показывает прямые ссылки, ожидаемые имена файлов и кнопку «Открыть папку». Положенные вручную файлы проверяются так же.

Если раздел `whisper` в настройках указывает на свои файлы (не те, что в каталоге), голос считается настроенным вручную: программа его не скачивает и не сверяет с суммами.

Сборки берутся из выпусков whisper.cpp на GitHub, модели — с Hugging Face; адреса закреплены на конкретной версии. При смене версии сборки имя и место выпуска сверяются заново: файлы для Windows лежат не в каждом выпуске.

Режим `Raskladushka.exe --voice-check --variant cpu|gpu --dir <папка> --runtime <библиотеки Visual C++> --out <отчёт.json>` ставит голос в указанную папку и распознаёт `selftest.wav` без окон. Им пользуется сборка выпуска.

## Обновления

- Раз в неделю программа запрашивает `https://api.github.com/repos/Lomer275/raskladushka/releases/latest`. Первая проверка — через пару минут после запуска.
- Черновики и предварительные выпуски не учитываются: программа видит только опубликованное.
- Если вышла новая версия, подсказка у значка предлагает открыть страницу выпуска. Сама программа ничего не скачивает и не ставит. Причина: программа читает каждое нажатие клавиши, и автообновление с одного аккаунта GitHub сделало бы захват этого аккаунта способом разослать всем программу-шпиона.
- «Сообщать об обновлениях» выключает проверку, «Проверить обновления» проверяет сразу.

## Установщик

Inno Setup, мастер на русском, `installer/Raskladushka.iss`.

- Ставит программу для текущего пользователя в `%LOCALAPPDATA%\Programs\Raskladushka`, без прав администратора.
- Программа собрана вместе с .NET, отдельно ставить ничего не нужно.
- Флажки: «Запускать вместе с Windows» (включён), «Значок на рабочем столе» (выключен), в конце — «Запустить Раскладушку». Ярлык в меню «Пуск».
- Обновление — установка поверх. Запущенную программу установщик закрывает командой `Raskladushka.exe --exit`: она подаёт сигнал работающему экземпляру и ждёт его завершения. Флажок автозапуска при обновлении показывает текущее состояние, поэтому выключенный автозапуск обновление не включит.
- Удаление убирает программу, ярлыки и автозапуск и спрашивает, удалить ли настройки, журнал и скачанный голос. При удалении без окон данные остаются.

## Буфер обмена

Всё, что программа сама кладёт в буфер (надиктованный текст, переведённое выделение), помечается форматами `ExcludeClipboardContentFromMonitorProcessing`, `CanIncludeInClipboardHistory` = 0 и `CanUploadToCloudClipboard` = 0. Без этой пометки при включённом журнале буфера (Win+V) и синхронизации надиктованный текст попадал бы в облако Microsoft.

Копию при переводе выделения делает само окно, и пометить её программа не может.

## Приватность

- Набранные клавиши хранятся только в памяти: текущее слово и последнее завершённое слово с набранными после него пробелами и знаками. Последнее слово нужно, чтобы клавиша исправления работала и после пробела; оно забывается с началом следующего слова и при любом сбросе буфера.
- В основной журнал не пишется ни набранный, ни надиктованный текст — только события: что произошло, в какой программе, в какую сторону сменили раскладку, длина слова, причина решения, длительности диктовки. Тексты исключений, которые могут содержать пользовательский ввод, в журнал и уведомления не попадают.
- Журнал исправленных слов `words.log` выключен. Включает его пользователь — галкой «Записывать исправленные слова» в меню значка. Тогда в файл попадают слова, которые пользователь исправил клавишей или автозамену которых отменил: по ним настраивается автосмена. Слова, переключённые автоматически и не оспоренные, туда не пишутся; поля паролей программа не обрабатывает вовсе.
- Звук с микрофона на диск не сохраняется и за пределы компьютера не уходит.
- Whisper принимает соединения только с этого же компьютера.
- В сеть программа ходит только за голосом (по просьбе пользователя) и за номером последней версии. В запросах — только номер версии программы.

## Журнал

`raskladushka.log` отвечает на вопрос «что программа сделала и почему». Первая строка после запуска — `Application started; version=…`.

- Каждая смена раскладки записана с программой, направлением, длиной слова и причиной решения.
- Диктовка — с длительностями, временем запуска Whisper и типом ошибки.
- Отключение обработки набора — с причиной: пауза, поле пароля, полный экран, исключение. Короткая проверка нового окна при смене фокуса (до 0,3 с) в журнал не пишется: строка `reason=password` означает настоящее поле пароля.
- `Typing: TapSkipped` объясняет, почему касание Alt ничего не сделало: `reason` — нечего исправлять, раскладка неизвестна или касание не взведено; `disarm` — что сняло взвод; `lastReset` и `external` — последний сброс буфера; `selection` — заметила ли программа выделение.
- `Selection:` — перевод выделения: `trigger`, `copyMs` и `lastCopyMs` (через сколько миллисекунд буфер изменился впервые и в последний раз), `copies`, `holdMs`, `overwritten=True` (перевод в буфере кто-то заменил). `nothing copied` с `reason` — ничего не скопировалось (`timeout`), скопировался пустой (`empty`) или слишком длинный (`tooLong`) текст. `clipboard busy` — буфер менялся без перерыва дольше 2 с.
- `Hook:` — переустановка перехвата, в том числе сторожем, медленный или упавший обработчик, залипший модификатор.

## Проверка

**Тесты ядра** — под Linux: таблица клавиш, буфер слова, детектор с мерой качества, чистка текста, состояния диктовки с подставными часами и подставным Whisper, каталог и установка голоса (неверная сумма, продолжение после обрыва, выбор варианта, переход на процессор), сравнение версий.

**Самопроверка** — режим `Raskladushka.exe --selftest`, он же пункт меню. Запускает пользователь в своём сеансе Windows. Программа открывает собственное окно и сама:

1. набирает слова в «не той» раскладке в обе стороны и сверяет результат и раскладку;
2. набирает правильные слова и убеждается, что они не тронуты;
3. проверяет клавишу исправления, Shift+Pause, в режиме Alt — перевод выделения касанием Alt, и отмену замены с записью в исключения;
4. набирает слово в поле пароля и убеждается, что оно не тронуто;
5. подаёт тестовую запись в диктовку в обход микрофона и сверяет текст;
6. меряет время от запуска Whisper до текста, видеопамять до и после, собственную память;
7. с укороченным отсчётом проверяет, что Whisper гасится.

Отчёт пишется в папку журнала.

**Сборка выпуска** (`.github/workflows/release.yml`, по метке `v*`) на машине GitHub с Windows:
- тесты ядра;
- сборка программы вместе с .NET и установщика;
- проверка таблиц импорта всех `.exe` и `.dll` программы и сборки под CUDA (`build/check_imports.py`): каждая нужная библиотека должна лежать рядом или входить в список системных библиотек чистой Windows 10 (`build/win10-system-dlls.txt`). Машина GitHub не чистая — на ней стоят Visual C++ и многое другое, — поэтому эта часть проверяется по файлам, а не запуском;
- установка без окон: файлы, ярлык, автозапуск; запуск и строка версии в журнале;
- установка поверх запущенной программы: программа закрылась, автозапуск сохранился, выключенный автозапуск не включился;
- удаление: программа, ярлык и автозапуск убраны, настройки остались;
- скачивание голоса для процессора по зашитым адресам и распознавание `selftest.wav`, затем то же из папки с русскими буквами в пути;
- контрольные суммы и **черновик** выпуска. Людям выпуск виден только после публикации вручную.

**Ресурсы — условия приёмки:**

| Что | Условие |
|---|---|
| Память программы в простое | до 80 МБ |
| Процессор в простое | около нуля |
| Видеопамять в простое | 0 |
| Whisper после 5 минут тишины | процесс завершён |

## Риски

| Риск | Что с ним делаем |
|---|---|
| Автосмена ошибается | мера качества в тестах; отмена касанием Alt с записью в исключения; автосмена отключается отдельно от остального |
| Две программы смены раскладки мешают друг другу | предупреждение при запуске, если видна Punto Switcher или KeyRay |
| Windows снимает медленный перехватчик клавиш | в обработчике только операции в памяти, без диска, сети и ожиданий; сторож переустанавливает перехват |
| Пользователь печатает следующее слово, пока идёт замена предыдущего | решение и замена — в обработчике, одним вызовом; проверяется самопроверкой на двух словах подряд |
| Видеокарта занята или драйвер обновился и сборка под CUDA не стартует | перезапуск на процессоре с уведомлением |
| Сборка whisper.cpp под CUDA 12.4 может не работать на новых видеокартах | переход на сборку для процессора |
| Антивирус примет программу за шпиона | открытый код, затем подпись файла; ложное срабатывание — в Microsoft на проверку |
| Smart App Control не даёт запустить неподписанные файлы | до подписи сказано в README |
| Захват аккаунта GitHub | двухфакторный вход, выпуск только вручную, никаких автообновлений |
| Античит в играх насторожится на перехват клавиатуры | в полноэкранных окнах программа не вмешивается; в README — совет ставить её на паузу |
