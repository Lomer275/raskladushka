# Данные для словарей

## Источник

Списки частых слов взяты из репозитория [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords), папка `content/2018/`. Списки построены по корпусу OpenSubtitles 2018.

Лицензия данных — **CC BY-SA 4.0** (по файлу README репозитория, проверено 08.10.2026). Код репозитория — MIT; код оттуда не используется.

## Что лежит здесь

| Файл | Что это | Как получен |
|---|---|---|
| `data/src/ru_50k.txt` | 50 000 самых частых русских слов, формат «слово число» | скачан без изменений: `content/2018/ru/ru_50k.txt` |
| `data/src/en_50k.txt` | 50 000 самых частых английских слов | скачан без изменений: `content/2018/en/en_50k.txt` |
| `data/test/ru_rare.txt` | 2000 редких русских слов для меры качества | из `content/2018/ru/ru_full.txt`: строки начиная с 60 001-й, только слова из букв `а–я`, `ё` длиной от 4, первые 2000 |
| `data/test/en_rare.txt` | 2000 редких английских слов для меры качества | то же из `content/2018/en/en_full.txt`, буквы `a–z` |
| `data/test/tech_words.txt` | технические слова латиницей для меры качества | составлен вручную, к источнику не относится |

## Команды подготовки

```bash
B=https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018
curl -o data/src/ru_50k.txt $B/ru/ru_50k.txt
curl -o data/src/en_50k.txt $B/en/en_50k.txt
curl -o /tmp/ru_full.txt   $B/ru/ru_full.txt
curl -o /tmp/en_full.txt   $B/en/en_full.txt
```

Редкие слова отбираются так: пропустить первые 60 000 строк полного списка, из остальных взять первое поле, привести к нижнему регистру, оставить совпавшие целиком с `[а-яё]{4,}` (для английского — `[a-z]{4,}`), взять первые 2000.

Полные списки (`*_full.txt`) в репозиторий не кладутся: они нужны только для отбора редких слов.
