# Раскладушка

Программа для Windows, которая:
- сама меняет раскладку, если слово набрано не в той;
- исправляет последнее слово или выделенный текст по короткому нажатию Alt;
- переводит речь в текст прямо на компьютере, без интернета и облачных сервисов.

Сидит значком в трее. В простое почти не расходует память и не занимает видеокарту.

**Скачать:** [страница выпусков](https://github.com/Lomer275/raskladushka/releases/latest), файл `Raskladushka-<версия>-setup.exe`.

Нужна Windows 10 или 11, 64-разрядная, с русской и английской (США) раскладками. Права администратора не нужны.

## Клавиши

| Клавиша | Что делает |
|---|---|
| Правый Ctrl (держать) | Голосовой ввод: говорите, пока держите. Отпустили — текст появится там, где курсор |
| Alt (коротко нажать и отпустить) | Перевести последнее слово в другую раскладку |
| Alt сразу после автосмены | Отменить замену и больше не трогать это слово |
| Выделить текст, затем коротко нажать Alt | Перевести выделенный текст в другую раскладку |
| Shift + Pause/Break | Перевести выделенный текст |

Автосмена срабатывает сама, когда слово закончено: после пробела, точки, запятой.

Alt исправляет слово, только если его нажали и отпустили одного, без других клавиш. Alt+Tab, Alt+Shift, Alt+буква и долгое удержание работают как обычно.

Выделенный текст Alt переводит, только если программа видела, как его выделяли: мышью, двойным или тройным щелчком, щелчком с Shift, Shift со стрелками, Home, End, PgUp, PgDn и Ctrl+A. Выделение, сделанное иначе (через поиск, Ctrl+L в браузере), программа не замечает, и тогда Alt работает как обычно.

## Установка

1. Скачайте установщик со [страницы выпусков](https://github.com/Lomer275/raskladushka/releases/latest).
2. Запустите его двойным щелчком.
3. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», потом «Выполнить в любом случае». Почему так — в разделе [«Неизвестный издатель»](#неизвестный-издатель).
4. В мастере установки можно оставить всё как есть. По умолчанию программа запускается вместе с Windows, значка на рабочем столе нет.

После первого запуска у значка в трее появится подсказка. Автосмена и Alt работают сразу. Голосовой ввод сначала нужно скачать — об этом ниже.

Если на компьютере работает Punto Switcher, KeyRay или другая программа смены раскладки, закройте её: две такие программы мешают друг другу. Раскладушка предупредит, если увидит такую.

Если в Windows нет русской или английской раскладки, программа скажет об этом при запуске. Добавить раскладку: «Параметры → Время и язык → Язык».

### Неизвестный издатель

Установщик пока не подписан цифровой подписью. Поэтому Windows пишет «Неизвестный издатель», а SmartScreen и антивирусы могут насторожиться: программа следит за нажатиями клавиш и сама набирает текст, как и любая программа смены раскладки. Код программы открыт, его можно прочитать в этом репозитории. Подпись — в планах.

Проверить, что файл скачался целиком и его не подменили по дороге, можно по контрольной сумме. Она лежит в файле `SHA256SUMS.txt` на той же странице выпуска. В PowerShell:

```powershell
Get-FileHash .\Raskladushka-0.2.0-setup.exe
```

Строка `Hash` должна совпасть с суммой из `SHA256SUMS.txt` (регистр букв не важен).

**Smart App Control.** Если в Windows 11 включено интеллектуальное управление приложениями (Smart App Control), оно не даст запустить неподписанный установщик. Кнопки «Выполнить в любом случае» там нет. Выключать эту защиту ради Раскладушки не советуем: лучше дождаться подписанной версии.

## Голосовой ввод

Распознавание речи делает [whisper.cpp](https://github.com/ggml-org/whisper.cpp) с моделью Whisper. Всё работает на вашем компьютере: звук никуда не отправляется и на диск не записывается.

### Как включить

Файлы для голоса в установщик не входят, их нужно скачать один раз. Нажмите в меню значка «Голосовой ввод: скачать…» или просто зажмите правый Ctrl — программа предложит скачать.

В окне есть два варианта:

| Вариант | Для чего | Скачать |
|---|---|---|
| Для видеокарты NVIDIA | Распознаёт быстро. Предлагается, если видеокарта NVIDIA есть | около 1,3 ГБ |
| Для процессора | Для любого компьютера | около 0,5 ГБ |

Перед скачиванием окно показывает, сколько свободно на диске. Варианту для видеокарты нужно около 2,5 ГБ свободного места, варианту для процессора — около 0,6 ГБ.

Прерванное скачивание продолжится с того же места. После скачивания программа сама проверяет голос на тестовой записи. Если вариант для видеокарты не заработал, окно предложит скачать вариант для процессора.

У каждого файла в программу зашита контрольная сумма. Файл, который с ней не совпал, программа не распаковывает и не запускает.

### Если скачивание не идёт

Если GitHub или Hugging Face недоступны, окно покажет прямые ссылки, имена файлов и кнопку «Открыть папку». Скачайте файлы любым способом и положите в эту папку, затем нажмите «Повторить». Суммы проверяются так же.

### Как пользоваться

Зажмите правый Ctrl, скажите фразу, отпустите. Внизу экрана виден индикатор: «Запись», «Загружаю модель…», «Распознаю…».

- Если, пока держите Ctrl, нажать другую клавишу, это обычное сочетание вроде Ctrl+C: запись отменяется.
- Запись короче 0,4 с и запись без звука не распознаются.
- Одна запись — не дольше 2 минут.
- После текста программа ставит пробел.

### Сколько ждать

- **С видеокартой NVIDIA** — обычно меньше секунды.
- **На процессоре** — несколько секунд. На сборочной машине GitHub с 4 потоками запись в 20 секунд распознаётся за 6 секунд, а короткая фраза ненамного быстрее длинной. Программа сама берёт половину ядер процессора, но не меньше 4 и не больше 8, поэтому на мощном процессоре быстрее.

Через 5 минут без диктовок программа выгружает модель и освобождает память. Поэтому первая фраза после перерыва ждёт ещё и загрузку модели — индикатор пишет «Загружаю модель…».

### Микрофон

Программа пишет с микрофона, выбранного в Windows по умолчанию. Если Windows запретила приложениям доступ к микрофону, включите его: «Параметры → Конфиденциальность и защита → Микрофон», переключатель для классических приложений.

### Если нет правого Ctrl

На некоторых новых ноутбуках на месте правого Ctrl стоит клавиша Copilot. Тогда голосу нужна другая клавиша:

1. В меню значка выберите «Открыть настройки» — откроется файл `settings.json` в Блокноте.
2. В разделе `dictation` поменяйте `"hotkey": "RControl"` на одно из значений: `RShift` (правый Shift), `RAlt` (правый Alt), `ScrollLock`, `Pause`, `F13`–`F24`.
3. Сохраните файл. Программа подхватит изменение сразу, перезапускать её не нужно.

С `RAlt` короткое нажатие правого Alt по-прежнему исправляет слово, а удержание включает запись.

| Голосовой ввод… | Скачать голос или проверить, как он работает |
| Записывать исправленные слова | Журнал слов `words.log`, по умолчанию выключен. Подробнее — в разделе «Приватность» |
| Открыть настройки | Файл `settings.json` в Блокноте |
| Открыть журнал | Папка с журналом программы |
| Самопроверка | Программа открывает своё окно, сама набирает тестовые слова и пишет отчёт в папку журнала |
| Автозапуск | Запускать вместе с Windows |
| Сообщать об обновлениях, Проверить обновления | См. «Обновления» |
| О программе | Версия, лицензия, сторонние лицензии |

## Настройки

Файл `%APPDATA%\Raskladushka\settings.json`. Программа перечитывает его при сохранении. Если в файле ошибка, программа скажет об этом и продолжит работать с прежними настройками.

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `dictation.hotkey` | `RControl` | Клавиша голоса: `RControl`, `RShift`, `RAlt`, `ScrollLock`, `Pause`, `F13`–`F24` |
| `dictation.language` | `ru` | Язык распознавания |
| `dictation.prompt` | пусто | Слова и термины, которые Whisper должен узнавать, через запятую |
| `dictation.microphone` | пусто | Имя микрофона; пусто — микрофон Windows по умолчанию |
| `dictation.idleUnloadMinutes` | `5` | Через сколько минут без диктовок выгружать модель |
| `layout.autoSwitch` | `true` | Автосмена раскладки |
| `layout.fixHotkey` | `Alt` | Клавиша исправления: `Alt` — короткое нажатие любого Alt; или `Pause`, `ScrollLock`, `F13`–`F24`. С отдельной клавишей выделенный текст переводит Shift + эта клавиша |
| `layout.minWordLength` | `3` | Слова короче не трогаются |
| `pauseInFullscreen` | `true` | Ничего не делать в полноэкранных приложениях |
| `exclusions.processes` | пусто | Программы, где Раскладушка ничего не делает, например `["game.exe"]` |
| `whisper.cpuThreads` | `0` | Потоков для распознавания на процессоре; `0` — выбрать самой |
| `updates.notify` | `true` | Сообщать о новых версиях |

Слова, которые не нужно переключать, лежат в `%APPDATA%\Raskladushka\exceptions.txt`, по одному в строке. Туда же попадают слова, автосмену которых вы отменили касанием Alt.

## Обновления

Раз в неделю программа узнаёт на GitHub номер последней версии. Если вышла новая, у значка появится подсказка «Вышла версия … — открыть страницу?». Сама программа ничего не скачивает и не ставит.

Чтобы обновиться, скачайте новый установщик и запустите его поверх старой версии. Работающую программу установщик закроет сам. Настройки, исключения и скачанный голос сохранятся. Если вы выключили автозапуск, обновление его не включит.

Пункт «Сообщать об обновлениях» выключает проверку, «Проверить обновления» проверяет сразу.

## Удаление

«Параметры → Приложения», найти в списке Раскладушку, «Удалить». Программа, ярлыки и автозапуск убираются. Перед этим удаление спросит, стереть ли заодно настройки, журнал и скачанный голос.

## Куда программа ходит в сеть

Только в двух случаях:
- **за голосом** — когда вы сами нажали «Скачать»: сборка whisper.cpp с GitHub, модель с Hugging Face;
- **за номером последней версии** — раз в неделю или по пункту «Проверить обновления», к `api.github.com`. Если выключить «Сообщать об обновлениях», сама программа туда не ходит.

В запросах есть только номер версии программы. Набранный и надиктованный текст, звук, журнал и настройки программа никуда не отправляет.

## Приватность

- Набранные клавиши живут только в памяти: текущее слово и последнее законченное. Их нужно знать, чтобы исправить слово по Alt.
- В полях ввода пароля программа ничего не делает.
- В журнал программы не пишется ни набранный, ни надиктованный текст. Там только события: что произошло, в какой программе, длина слова, причина решения, длительности.
- Журнал слов `words.log` выключен. Если включить «Записывать исправленные слова», туда будут записываться слова, которые вы исправили по Alt или чью автосмену отменили. Файл лежит открытым текстом у вас на диске и нужен, чтобы понять, где автосмена ошибается.
- Текст, который программа сама кладёт в буфер обмена (надиктованный и переведённый), помечен «не сохранять в журнал буфера и не отправлять в облако».
- Одна оговорка. Чтобы перевести выделенный текст, программа просит окно скопировать его. Эту копию делает само окно, и пометить её программа не может. Если в Windows включены журнал буфера обмена (Win+V) и синхронизация между устройствами, выделенный текст попадёт туда так же, как при обычном Ctrl+C.

## Ограничения

- **Окна, запущенные от имени администратора.** В них программа не может ни сменить раскладку, ни исправить слово: Windows не разрешает обычным программам вмешиваться в такие окна.
- **Игры с античитом.** Античит может принять перехват клавиатуры за читерство. В полноэкранных играх программа и так ничего не делает, но перед игрой с античитом лучше поставить её на паузу или добавить игру в `exclusions.processes`.
- **Слово перед Enter и Tab** автосмена не трогает: заменять уже поздно, текст мог уйти.
- **Пары частых слов**, которые набираются одними клавишами, остаются как набраны: «руку» и `here`, «рук» и `her`. Такие слова исправляются коротким нажатием Alt.
- **Только русская и английская (США) раскладки.**

## Если что-то не так

- В меню значка — «Самопроверка». Она проверит автосмену, исправление по Alt и голос и запишет отчёт в папку журнала.
- Журнал: «Открыть журнал» в меню значка, файл `raskladushka.log`. Набранного текста в нём нет, но есть имена программ, в которых вы работали. Посмотрите его, прежде чем кому-то отправлять.
- Сообщить об ошибке — в [Issues](https://github.com/Lomer275/raskladushka/issues).

## Для разработчиков

Как программа устроена — в [docs/design.md](docs/design.md).

Нужен .NET 8 SDK. Тесты и сборка программы идут и под Linux.

```bash
# тесты ядра
dotnet run --project tests/Raskladushka.Core.Tests -c Release

# мера качества автосмены, отчёт в artifacts/quality.md
dotnet run --project tests/Raskladushka.Core.Tests -c Release -- -trait "Category=Quality"

# сборка программы под Windows
dotnet publish src/Raskladushka.App -c Release -r win-x64 --self-contained true -o artifacts/publish
```

Тесты запускаются через `dotnet run`, а не `dotnet test`: тестовый проект на xunit v3 собран как исполняемый файл.

Установщик собирается Inno Setup 6 из `installer/Raskladushka.iss`:

```powershell
ISCC.exe /DAppVersion=0.2.0 /DPublishDir=<папка сборки> /DRuntimeDir=<папка с библиотеками Visual C++> installer\Raskladushka.iss
```

Выпуск собирает GitHub Actions по метке `v*` — см. [.github/workflows/release.yml](.github/workflows/release.yml). Сценарий на машине GitHub с Windows прогоняет тесты, собирает установщик, проверяет таблицы импорта библиотек, ставит, обновляет и удаляет программу, скачивает голос и распознаёт тестовую запись, затем создаёт черновик выпуска.
