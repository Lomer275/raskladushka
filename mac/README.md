# Раскладушка для Mac

Нужна macOS 13 или новее. Программа работает на Mac с Apple Silicon и Intel.
Звук распознаёт сервер команды: компьютер должен быть в сети команды.

## Где взять и как открыть

На странице [сборок macOS](https://github.com/Lomer275/raskladushka/actions/workflows/mac.yml)
откройте последнюю успешную сборку. Внизу, в разделе Artifacts, скачайте
`Raskladushka-mac` (для скачивания нужен вход в GitHub). Артефакты хранятся 14 дней.
Распакуйте скачанное, затем `Raskladushka-mac-<версия>.zip` внутри.
Перенесите «Раскладушка.app» в «Программы».

При первом запуске нажмите на программу правой кнопкой и выберите «Открыть»,
затем подтвердите открытие. Программа не проходила проверку Apple.
Значок микрофона появится в строке меню; в Dock значка нет.

## Разрешения

Разрешите три доступа в «Системные настройки → Конфиденциальность и безопасность»:

- «Микрофон» — для записи голоса.
- «Мониторинг ввода» — чтобы программа видела правый Option.
- «Универсальный доступ» — для вставки текста.

Если доступа нет, в меню микрофона будет строка, открывающая нужную панель.
Без мониторинга ввода программа не видит удержание клавиши: откройте меню мышью.
После включения разрешений при необходимости закройте и снова запустите программу.

**После каждого обновления** заново включите «Универсальный доступ» и «Мониторинг ввода»:
выключите старую строку «Раскладушка», удалите её кнопкой «−», запустите новую
программу и включите разрешение снова. Это нужно из-за меняющейся подписи приложения.

## Подключение сервера

В меню микрофона выберите «Сервер распознавания…».
Адрес и ключ выдаёт Костя; ключ передаётся через 1Password.
Вставьте полный адрес, начинающийся с `http://` или `https://`, и ключ.

«Проверить» отправляет секунду тишины с введёнными адресом и ключом, не сохраняя
их и не включая микрофон. Если сервер ответил и ключ подошёл, появится время ответа.
Сам текст на тишине пустой — так и должно быть; распознавание проверьте диктовкой после сохранения.
«Сохранить» запоминает введённые данные без обращения к серверу.
Ключ хранится в связке ключей Mac, адрес — в настройках приложения.
Пустой адрес можно сохранить, чтобы отключить подключение.

## Как диктовать

Поставьте курсор в поле текста, например в VS Code. Нажмите и держите **правый Option**,
говорите, затем отпустите клавишу. Значок покажет «Запись», затем «Распознаю…».
Текст появится у курсора. Прежний буфер обмена восстановится через полсекунды,
если вы за это время ничего другого не скопировали.

Левый Option для диктовки не используется. Если вместе с правым Option нажать
другую клавишу, запись будет молча отменена, а сочетание сработает как обычно.
Удержание короче 0,3 секунды тоже отменяется. Через 120 секунд запись остановится
и отправится сама. Во время распознавания новое удержание игнорируется.

При ошибке выберите «Отправить последнюю запись ещё раз» в меню микрофона.
Последняя запись хранится только в памяти до начала следующей записи или выхода.
Повторная отправка снова вставит текст, даже если первая попытка уже была успешной.

## Сообщения

Сообщение появляется у строки меню на четыре секунды и не забирает курсор.
Подсказка о мониторинге ввода при запуске держится десять секунд.

| Сообщение | Что делать |
|---|---|
| Ключ не подходит. Проверьте ключ в настройках сервера. | Проверьте ключ из 1Password; если не помогло, обратитесь к Косте. |
| Сервер занят. Запись можно отправить ещё раз из меню. | Подождите и отправьте последнюю запись из меню. |
| Сервер не ответил вовремя. Запись можно отправить ещё раз из меню. | Повторите отправку; при повторении обратитесь к Косте. |
| Сервер недоступен. Проверьте, что компьютер в сети команды. | Подключитесь к сети команды и отправьте запись снова. |
| Не удалось распознать запись. | Повторите отправку или надиктуйте заново; если ошибка повторяется, обратитесь к Косте. |
| Укажите сервер распознавания в меню значка. | Откройте настройки сервера и сохраните адрес и ключ. |
| Раскладушка не слышит правый Option. Разрешите «Мониторинг ввода» — строка в меню значка. | Откройте меню значка, нажмите строку о мониторинге ввода и включите «Раскладушку». |
| Разрешите доступ к микрофону | Включите «Микрофон» в системных настройках. |
| Разрешите мониторинг ввода | Включите «Мониторинг ввода» в системных настройках. |
| Разрешите универсальный доступ | Включите «Универсальный доступ» в системных настройках. |
| Адрес должен начинаться с http:// или https://. | Введите полный адрес сервера, полученный от Кости. |
| Не удалось сохранить настройки сервера. | Проверьте доступ к связке ключей и повторите сохранение. |
| Не удалось подготовить ключ сервера. | Проверьте доступ к связке ключей, заново введите ключ. |
| Сохранено. | Настройки сохранены; попробуйте диктовку. |
| Сервер ответил за … с. | Проверка прошла; сохраните настройки. |

Распознанный текст, ключ и адрес сервера не записываются в журнал.
При недоступном сервере распознавания на самом Mac нет.
